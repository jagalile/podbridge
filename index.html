Ajustes

Puente (Cloudflare Worker)

GitHub Pages es estático y no puede saltarse CORS ni hablar el protocolo privado de Pocket Casts. Despliega el Worker incluido en /worker y pega aquí su URL.

Relevo para episodios grandes (opcional)

Cloudflare no consigue mantener fiable la subida de episodios de más de ~100 MB. Despliega el servicio incluido en /relay-service en Render.com (gratis) y pega aquí su URL y el secreto que le hayas puesto — ver el README para el paso a paso. Sin esto, esos episodios grandes solo se pueden descargar y subir a mano.

Cuenta de Pocket Casts

Tus credenciales viajan directamente a tu propio Worker y de ahí a Pocket Casts — nunca se guardan en un servidor de terceros. La contraseña nunca se guarda en ningún sitio.

Conectado como

El token se guarda cifrado con una clave que nunca sale de este navegador (no la contraseña, que nunca se guarda). No lo actives en un ordenador compartido — desactiva el interruptor de arriba para olvidarla en cualquier momento.

Tus datos

Favoritos, historial de subidas, la URL del Worker y la configuración del relevo (URL y secreto), en un archivo que puedes guardar o llevar a otro navegador. Nunca incluye contraseñas ni el token de Pocket Casts.
